# String Matching Problem

Compare string a with string b, or string a with itself&#x20;

Case:&#x20;

* Longest Palindrome Subsequence
* If string a match pattern b
* Edit string a to become string b

Keys:

* At least 2D (need to iterate string a for every character in string b)
  * O(M \* N) if M = len(a) and N = len(b)
* Iterations is same directions (start to finish or finish to start)
